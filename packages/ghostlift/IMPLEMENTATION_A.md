## Core build (v0.1, tiers 1 and 2-Python)
Package `ghostlift` 0.1.0 under src/ghostlift/, Python stdlib only, zero dependencies:
- marshal_safe.py - a from-scratch parser for the CPython marshal byte stream. It never calls marshal.loads / marshal.load, never constructs a real code object, and never imports or executes anything named by an artifact. Code objects come back as a CodeData dataclass (plain data). Limits: max file payload handled by the pyc layer (64 MB), max objects 1,000,000, max nesting depth 100, max string/bytes 64 MB, max container items 1,000,000. Limit hits and malformed streams raise SafeMarshalError.
- pyc.py - 16-byte .pyc header parsing (magic, hash-based flag, timestamp/size). Supported magics are pinned to tested code-object layouts: 3495 (3.11), 3531 (3.12), 3571 (3.13). Unknown magic is refused by name. Development note: the 3.12 field order (argcount, posonlyargcount, kwonlyargcount, stacksize, flags, code, consts, names, localsplusnames, localspluskinds, filename, name, qualname, firstlineno, linetable, exceptiontable) was pinned empirically against compiled samples before the parser was written, and the parser was verified to consume test streams exactly to EOF.
- reconstruct.py - Tier 2 structured reconstruction: def/class lines rebuilt from code-object metadata, including positional-only markers, keyword-only args, *args, **kwargs, async def, generator markers, nested functions and methods, docstrings (module, function, and class, with a class-specific extraction that does not mistake the class-name const for the docstring; one bug there was caught and fixed during the smoke test). Bodies are placeholders; an approximate adaptive-bytecode listing is appended per function as comments, labelled for reading only. Honest non-recoveries, stated in every lifted file header: default argument values, decorators, class bases, original bodies, comments, formatting.
- sourcemap.py - Tier 1 exact recovery from version 3 source maps: sourcesContent recovered byte for byte, sources without embedded content reported by name as not recovered, output paths sanitised (absolute prefixes and .. components cannot escape the output tree; rewritten paths are flagged in the manifest and in the result).
- core.py - inspect_artifact() and lift_path(). Output tree is Slice-shaped: <out>/files/... plus <out>/manifest.json in the GhostSlice bundle style (per file: path, mode "lifted", sha256, tokens_estimate with a "chars/4 estimate" method label), plus GhostLift watermark fields on every entry: lifted: true, tier, tier_name, recovery ("exact" / "structured"), source_artifact, source_sha256, and a plain-words manifest note that lifted files are not original source. Tier 2 Python files also carry the in-file header `# ghostlift: lifted tier=2 source=pyc reconstruction=structured`. Tier 1 files are written byte-exact (their watermark is the manifest, by design, so exactness is provable).
- cli.py - `ghostlift inspect <artifact> [--json]` and `ghostlift lift <artifact-or-folder> -o <out>`, also runnable as `python3 -m ghostlift`. Lift accepts a folder and processes every .pyc / .map under it, itemising failures per artifact instead of aborting.
- Tier 3 (.class / .dex / .dll / .wasm / .exe / .so / .dylib) and JavaScript inputs: inspect detects and reports them honestly (Tier 3 = detected only in v0.1; JS = Tier 2 target, core lift not in Agent A's build, matching Agent B's README, which names the examples/ JS lifter as the tested JS reference).

## Known limits, plainly
- Code-object layouts are only tested on this machine's CPython 3.12; 3.11 and 3.13 magics are accepted on the basis of the same documented layout family and are NOT smoke-tested here. Parent verification on other interpreters is still owed before any support claim is published.
- Bytecode comment listings decode CPython 3.12 adaptive bytecode approximately (specialised opcodes, cache skipping via opcode._inline_cache_entries); they are reading aid in comments, not a disassembler claim.
- Marshal dict parsing keeps the parse going on unhashable hostile keys by dropping that pair; sets/frozensets/floats/complex/longs are supported as const values, exotic const types beyond the parser's set raise SafeMarshalError and the lift is refused rather than approximated.
- pyproject.toml declares readme = "README.md" (Agent B's file, present in the tree); packaging was exercised via PYTHONPATH=src in all runs above, a full `pip install .` was not run by this agent.
