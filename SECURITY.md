# Security Policy

## Supported versions
Only the latest release receives security fixes.

## Reporting a vulnerability
Please do **not** open a public issue. Use GitHub's private
[security advisory](https://github.com/littlestjames82-sys/ghostslice/security/advisories/new)
form. Expect an initial response within 7 days.

GhostSlice is local-first with zero dependencies; reports about secret
leakage in generated bundles (redaction bypasses) are especially welcome.
